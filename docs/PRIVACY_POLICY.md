# 隐私政策

**最后更新：2025-01-01**

PhiraForge（以下简称"本应用"）由开发者 mouya 开发，致力于保护用户隐私。

## 数据收集

本应用**不收集任何用户个人数据**。

- 不收集设备标识符（IMEI、Android ID 等）
- 不收集位置信息
- 不收集联系人信息
- 不收集使用行为统计
- 不内置任何分析 SDK

## 数据处理

### 音频文件
- 用户选择的音频文件**仅在本地设备**解码和分析
- 音频文件不会被上传至任何服务器
- 处理完成后临时文件自动删除

### AI API（可选功能）
当用户明确启用 AI 增强功能时，以下**匿名摘要数据**将发送至用户配置的 AI API 地址：

| 数据 | 说明 |
|------|------|
| BPM | 每分钟节拍数（数值） |
| Onset 数量 | 检测到的节奏点数量（整数） |
| 音频时长 | 秒（数值） |
| 目标难度 | Easy/Normal/Hard/Extra（字符串） |

**不发送的数据**：
- 音频原始数据或文件
- 文件名或文件路径
- 设备信息
- 用户身份信息

### API Key 存储
- API Key 使用 AndroidX EncryptedSharedPreferences (AES256-GCM) 加密存储
- 不在日志中记录 API Key
- 不向第三方分享 API Key

## 权限使用

| 权限 | 用途 | 是否必需 |
|------|------|----------|
| READ_MEDIA_AUDIO | 读取用户选择的音频文件 | 必需 |
| READ_EXTERNAL_STORAGE | 读取音频文件（Android 12 及以下） | 必需 |
| INTERNET | AI API 请求（仅启用 AI 时使用） | 可选 |
| ACCESS_NETWORK_STATE | 检测网络状态 | 可选 |

## 日志

本应用使用 Android Log 输出诊断信息。日志经过 `PFLog` 工具脱敏处理：
- API Key 自动替换为 `[REDACTED]`
- 文件路径自动替换为 `[path]`
- 日志内容截断至 500 字符

## 第三方服务

本应用不集成任何第三方分析、广告或追踪服务。

AI API 服务由用户自行配置，本应用不预置任何 AI 服务商。

## 数据删除

- 卸载应用将删除所有本地数据（设置、缓存）
- AI API Key 在卸载后自动删除
- 不存在服务器端数据需要清理

## 儿童隐私

本应用不针对 13 岁以下儿童。不会故意收集儿童个人信息。

## 政策变更

隐私政策如有变更，将在 GitHub 仓库和应用更新日志中公布。

## 联系方式

如有隐私相关问题，请通过 [GitHub Issues](https://github.com/mouya-q/PhiraForge/issues) 联系。
