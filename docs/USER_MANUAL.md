# 用户手册

## 安装

1. 从 [GitHub Releases](https://github.com/mouya-q/PhiraForge/releases) 下载最新 APK
2. 在手机上允许「安装未知来源应用」
3. 安装 `PhiraForge-x.x.x.apk`

## 基本使用

### 第一步：导入音频

1. 打开 PhiraForge
2. 在「生成」页面点击「导入音频」
3. 在文件选择器中选择音频文件
4. 支持的格式：MP3、WAV、OGG、FLAC、M4A、AAC
5. 选择后会显示文件名，表示导入成功

### 第二步：选择难度

选择四个难度等级之一：

| 难度 | 特点 | 适合人群 |
|------|------|----------|
| Easy | 稀疏 Tap，慢速 | 音游新手 |
| Normal | 中等密度，偶尔 Hold | 休闲玩家 |
| Hard | 高密度，多种音符类型 | 进阶玩家 |
| Extra | 最高密度，复杂排布 | 高手挑战 |

### 第三步：（可选）设置 BPM

- 留空 → 自动检测 BPM
- 手动输入 → 使用指定 BPM 生成谱面
- 如果自动检测的 BPM 明显不对，建议手动输入

### 第四步：开始生成

1. 点击「开始生成」
2. 观察进度条：
   - 解码音频中… → 将音频解码为 PCM
   - 分析节奏中… → FFT 频谱分析 + onset 检测
   - 生成谱面中… → 将 onset 转换为音符
   - 生成完成 → 谱面已就绪
3. 可随时点击「取消生成」中止

### 第五步：预览谱面

1. 切换到「预览」页面
2. 查看谱面统计：
   - 物量（音符总数）
   - 判定线数
   - BPM
   - 时长
   - NPS（每秒音符数）
3. 查看时间轴可视化：
   - 绿色圆点 = Tap
   - 蓝色圆点/线条 = Hold
   - 橙色圆点 = Flick
   - 紫色圆点 = Drag
4. 查看音符类型分布

### 第六步：导出谱面

1. 在生成成功卡片中点击「导出谱面」
2. 选择保存位置和文件名
3. 导出的是 `.json` 文件，即 RPE 格式谱面

### 第七步：在 Phira 中游玩

1. 创建一个文件夹，将以下文件放入：
   - 导出的 `.json` 谱面文件
   - 对应的音频文件（MP3 等）
2. 打开 Phira
3. 选择「本地」→ 导入该文件夹
4. 选择难度开始游玩

## AI 增强（可选）

### 配置 AI API

1. 进入「设置」页面
2. 在「AI 配置」部分：
   - 勾选「启用 AI 增强」
   - 填写 API 地址（默认 OpenAI）
   - 填写 API Key
   - 填写模型名称
   - 设置超时时间
3. 点击「测试连接」验证配置

### 支持的 AI 服务商

任何兼容 OpenAI Chat Completions API 的服务商：
- OpenAI (gpt-4o-mini)
- DeepSeek (deepseek-chat)
- Moonshot (moonshot-v1-8k)
- 其他兼容服务商

### AI 失败回退

如果 AI API 不可用（网络错误、超时、认证失败等），应用会自动回退到离线生成，不会中断主流程。

## 设置说明

| 设置项 | 说明 |
|--------|------|
| 主题模式 | 跟随系统 / 浅色 / 深色 |
| 默认难度 | 打开应用时的默认选择 |
| 谱面偏移 | 谱面整体时间偏移（毫秒），正值延后 |
| AI 启用 | 开关 AI 增强功能 |
| API 地址 | OpenAI 兼容 API 的完整 URL |
| API Key | 加密存储，不会泄露 |
| 模型名称 | AI 模型标识 |
| 超时 | AI 请求超时时间（秒） |

## 权限说明

| 权限 | 用途 |
|------|------|
| READ_MEDIA_AUDIO | 读取音频文件（Android 13+） |
| READ_EXTERNAL_STORAGE | 读取音频文件（Android 12 及以下） |
| INTERNET | AI API 请求（可选功能） |
| ACCESS_NETWORK_STATE | 检测网络状态 |

## FAQ

### Q: 生成的谱面在 Phira 中无法加载？
检查以下几点：
- 确保 JSON 文件结构完整（用 JSON 查看器检查）
- 确保音频文件与谱面在同一文件夹
- 尝试降低难度重新生成

### Q: BPM 检测不准确？
BPM 自动检测基于自相关算法，对于节奏不明确的音频可能不准确。建议手动输入已知 BPM。

### Q: 生成的谱面太难/太简单？
调整难度等级。Easy 适合新手，Extra 适合高手。也可以通过修改「谱面偏移」微调时间精度。

### Q: AI 增强有什么效果？
AI 会分析音频的整体特征（BPM、onset 数量、时长），建议密度曲线、段落边界和音符类型分布，用于优化谱面的结构合理性。

### Q: 应用会上传我的音频文件吗？
不会。音频文件完全在本地解码和分析。AI 功能仅发送 BPM、onset 数量等匿名摘要数据。
